• Formatted text: nananatili ang bold, italic, at mga link kapag ipinaste.
• Eksakto ang code: nakikilala ng Cutling ang code at pinapanatili itong monospace, walang smart quotes o dash.
• Pindutin nang matagal ang Option habang kini-click ang isang Cutling para i-paste ito bilang plain text, o i-on ang “Laging i-paste bilang plain text” sa Settings.
