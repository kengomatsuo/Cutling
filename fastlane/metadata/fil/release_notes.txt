• Formatted text: nananatili ang bold, italic, at mga link kapag kinopya. I-tap ang isang Cutling sa keyboard para makopya ito kasama ang format, saka i-paste.
• Eksakto ang code: nakikilala ng Cutling ang code at pinapanatili itong monospace, walang smart quotes o dash.
• I-type sa keyboard ang simula ng pangalan ng isang Cutling at i-tap ito para palitan ang salita.
• I-import sa Cutling ang Pagpalit ng Text ng iyong iPhone.
• Nagdaragdag ang keyboard ng space bago ang Cutling kapag kailangan, at gumagana ito sa mga field na plain na character lang ang tinatanggap.
