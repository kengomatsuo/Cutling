Kebijakan Privasi

Berlaku sejak 8 Maret 2026

Cutling tidak mengumpulkan, menyimpan, atau mengirimkan data Anda kepada pengembang. Data Anda tetap berada di perangkat Anda, atau disinkronkan secara privat melalui akun iCloud Anda sendiri, dan sinkronisasi itu bersifat opsional.

Gambaran Umum

Cutling adalah ekstensi keyboard yang memungkinkan Anda menyimpan lalu menyisipkan teks dan gambar dengan cepat, seperti alamat, tanda tangan, kode QR, dan hal lain yang sering Anda pakai. Kebijakan ini menjelaskan bagaimana aplikasi memperlakukan data Anda.

Pengumpulan Data

Tidak ada data pribadi yang dikumpulkan sama sekali: tidak ada analitik, tidak ada laporan kerusakan, tidak ada pelacakan penggunaan, tidak ada pengenal iklan. Aplikasi ini tidak memuat kerangka kerja analitik maupun pelacakan dari pihak ketiga. Pengembang tidak memiliki kemampuan untuk membaca, menjangkau, atau mengambil data Anda.

Cutling Anda

Setiap cutling yang Anda buat, baik teks maupun gambar, disimpan secara lokal di perangkat Anda. Data Anda tidak pernah dikirim ke pengembang maupun ke server pihak ketiga mana pun.

Sinkronisasi iCloud (opsional)

Cutling menyediakan sinkronisasi iCloud opsional agar cutling Anda tetap selaras di semua perangkat Apple Anda:

  • Cutling disinkronkan melalui akun iCloud Anda sendiri menggunakan basis data privat CloudKit milik Apple.
  • Hanya Anda yang dapat mengakses data yang disinkronkan, melalui Apple ID Anda.
  • Pengembang tidak memiliki akses ke data iCloud Anda.
  • Anda dapat mematikan sinkronisasi kapan saja di pengaturan aplikasi.

Kalau sinkronisasi iCloud dimatikan, data Anda tetap sepenuhnya berada di perangkat Anda. Sinkronisasi iCloud disediakan oleh Apple dan tunduk pada syarat dan ketentuan iCloud Apple.

Ekstensi Keyboard

Cutling menyertakan ekstensi keyboard khusus yang memerlukan Akses Penuh untuk membaca papan klip perangkat. Izin itu dipakai hanya agar Anda bisa menempel dan mengelola cutling yang tersimpan. Keyboard tidak mencatat, merekam, atau mengirimkan ketikan maupun isi papan klip Anda. Seluruh akses ke papan klip terjadi secara lokal di perangkat.

Layanan Pihak Ketiga

Cutling tidak menggunakan layanan, SDK, atau API pihak ketiga, dan tidak ada data yang dikirim ke server luar.

Privasi Anak

Tidak ada data yang dikumpulkan dari siapa pun, termasuk anak di bawah 13 tahun. Aplikasi ini aman untuk segala usia.

Perubahan Kebijakan Ini

Kalau kebijakan ini diperbarui, perubahannya akan dimuat di halaman ini dengan tanggal berlaku yang baru.

8 Maret 2026: diperbarui untuk mencakup penambahan cutling gambar dan fitur sinkronisasi iCloud opsional, sekaligus menegaskan bahwa sinkronisasi iCloud bersifat opsional, dapat dimatikan, dan data yang disinkronkan berada di akun iCloud Anda sendiri.
