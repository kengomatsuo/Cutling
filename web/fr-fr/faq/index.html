Questions fréquentes

Qu’est-ce qu’un « cutling » ?

Un cutling est un élément enregistré : un texte ou une image que vous voulez garder à portée de main. Voyez-le comme un morceau prélevé sur votre presse-papiers, que vous pouvez replacer où bon vous semble, autant de fois que nécessaire.

Comment configurer le clavier Cutling ?

Allez dans Réglages > Général > Clavier > Claviers > Ajouter un clavier…, puis choisissez Cutling. Touchez ensuite Cutling dans la liste et activez « Autoriser l’accès complet ». Un guide de configuration est également disponible dans l’app.

Pourquoi le clavier a-t-il besoin de l’accès complet ?

L’accès complet permet au clavier de lire vos cutlings dans le stockage local de l’appareil, et donc de vous les présenter. Cutling ne s’en sert ni pour enregistrer vos frappes, ni pour accéder à Internet, ni pour envoyer quoi que ce soit où que ce soit. Tout reste sur l’appareil.

Mes données sont-elles en sécurité ?

Oui. Aucune donnée n’est collectée : pas de statistiques, pas de suivi, pas de rapports de plantage, pas de SDK tiers. Les cutlings sont stockés localement sur l’appareil, ou dans votre propre compte iCloud si vous activez la synchronisation. Le développeur n’a aucun moyen d’accéder à vos données.

Comment fonctionne la synchronisation iCloud ?

Une fois activée, elle passe par la base de données privée CloudKit d’Apple pour garder vos cutlings à jour sur vos appareils Apple. Vous seul y avez accès, avec votre compte Apple. Le développeur n’a accès à aucune donnée synchronisée. La synchronisation est facultative et se désactive à tout moment dans les réglages.

Y a-t-il une limite au nombre de cutlings ?

Jusqu’à 100 cutlings texte et 25 cutlings image. Chaque cutling texte peut contenir 2 000 caractères.

Cutling fonctionne-t-il sur Mac ?

Oui. Sur Mac, Cutling se loge dans la barre des menus et s’ouvre de partout avec un raccourci clavier global. Vous choisissez un cutling, il est collé directement dans l’app que vous utilisiez. Avec la synchronisation iCloud activée, vos cutlings restent les mêmes sur iPhone, iPad et Mac.

Y a-t-il un abonnement ou des achats intégrés ?

Non. Cutling s’achète une seule fois : aucun abonnement, aucun achat intégré, aucune publicité. Vous payez une fois, l’app est à vous pour toujours.

Que deviennent les cutlings supprimés ?

Ils partent dans le dossier « Supprimés récemment » et y restent 30 jours. Vous pouvez les restaurer pendant ce délai, ou les laisser disparaître d’eux-mêmes.

Comment installer la version Mac ?

Deux possibilités, toutes deux sur la page de téléchargement. Depuis le Mac App Store, l’installation se fait comme pour n’importe quelle app. Sinon, téléchargez l’app directement et gratuitement : elle est signée avec un Developer ID et notarisée par Apple, donc elle s’ouvre normalement, sans alerte de sécurité. Ouvrez le DMG et faites glisser Cutling dans votre dossier Applications.

Qu’est-ce que le collage direct sur Mac, et pourquoi demande-t-il l’accès à l’accessibilité ?

Le collage direct est facultatif. Quand il est activé, choisir un cutling dans le sélecteur envoie un simple ⌘V à l’app que vous utilisiez, si bien que le texte arrive à l’emplacement du curseur. macOS exige l’accès à l’accessibilité pour envoyer cette frappe. L’option est désactivée par défaut ; dans ce cas, Cutling se contente de copier dans le presse-papiers et vous collez vous-même.
