# Release posts: shapes that work, per platform

Source: notes.md rows (28 posts, captured 2026-11-21). Engagement is as visible at capture and depends mostly on audience size, so compare per follower and per view, not per like. Not reached: Snippety, Maccy, Clipy, Mona, Ice, Hand Mirror, Halide (only one post inside 18 months seen, not saved), Drafts (last post Dec 2023). TextExpander's and Paste's pain-led posts did not beat their feature posts; the owner's pain-first rule is not proven by this data. The one case where it fits cleanly (row 5) got few likes. Treat pain-first as GUESS until Cutling tests it.

## X
1. Teaser line, video only, no link, before the release: Paste row 1 (64 likes vs 20 for its release post, row 2), CleanShot row 13 (1K likes, "Next week" plus dated image).
2. Name, the pain in one short line, scannable emoji list, demo video of a person using it: Raycast rows 6, 7, 8, 9 (151 to 2.1K likes). Works with an audience; for a small account it reads as a feature list.
3. One plainly worded, highly requested feature, blog link, no list, no hashtag: Things rows 16 and 17 (363 to 490 likes).
4. Pain first, then the fix and a demo: CleanShot row 14, TextExpander rows 10 and 11, Paste row 5. Moderate to no engagement; the pain must be a concrete moment, not a slogan.
5. Closing line on the price stance: CleanShot row 12 ("No subscription required").
6. Small-account floor: "New in X / one line" gets 5 to 10 likes, 300 to 600 views (PastePal row 19, Yoink maker rows 21 and 22). A question with a screenshot of a real problem got 4x the views (PastePal row 18). Milestone posts get 2 to 5x (row 20).
No rival uses more than 4 hashtags; Raycast, Things, CleanShot (release) use none.

## Threads
1. Same text as X, link in the body, no tag: Raycast rows 23 and 24 (20 to 25 likes on about 5K followers).
2. Platform-release post with the maker answering replies: Things row 25 (118 likes, 4.4K views on 4.5K followers; far better per follower than X).
3. One topic tag per post: Paste row 26 (11 likes on 52 followers). No rival ends on a question; GUESS that it would raise replies.
4. Anchor on the habit the reader already has on Mac: Raycast row 23.
