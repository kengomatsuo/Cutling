			Add lists in Notes on Mac
Organize your lists by adding bulleted, dashed, and numbered lists to notes. If you are using iCloud notes or notes stored on your Mac, you can also add checklists.
Note: All Notes features described in this guide are available when using iCloud notes. Some features aren’t available when using accounts from other providers.
Open Notes for me
Add and change a list
Go to the Notes app  [IMG: ]  on your Mac.
In a note, click where you want to add a list.
To create a list, do any of the following:
Click  [IMG: the Format button] , then choose a list option, such as bulleted or dashed.
Click  [IMG: the Checklist button]  to add a checklist (or use the Touch Bar).
Tip: To start a list, type a character followed by a space: an asterisk for a bulleted list, a hyphen for a dashed list, or a number and a period for a numbered list.
To change a list, do any of the following:
Add to a list: Click at the end of a list item, then press Return.
End a list (and add a new paragraph): Click at the end of the last line item, then press Return twice.
Increase list level: Click a line in the list, then press Tab to indent.
Decrease list level: Click a line in the list, then press Shift-Tab.
Add a line break (soft return) to a list item: Press Shift-Return at the end of a list item to start a new line without starting a new list item.
Move a list item up (or down) in the list: Press Control-Command-Up Arrow (or Control-Command-Down Arrow).
Change a checklist
The same changes you make to a list can be made to a checklist. In addition to those changes, you can also check or uncheck items, reorder items, and convert existing paragraphs into a checklist.
Go to the Notes app  [IMG: ]  on your Mac.
Open a note, then do any of the following:
Convert paragraphs into a checklist: Select the paragraphs you want to turn into a checklist, then click  [IMG: the Checklist button] . 
Each paragraph becomes an item in the checklist.
Reorder items in a checklist: Click and hold a checklist item, then drag it to a new location.
Check or uncheck one item: Click a circle to mark an item as complete. Click the circle again to mark it as incomplete.
To automatically move checklist items to the bottom of the list as they are checked, select “Automatically sort checked items” in Notes settings.
Check or uncheck all items: Choose Format > More > Check All or Uncheck All.
You can also Command-click any checklist item. If any item is unchecked, all items are checked (and vice versa).
