			Add links in Notes on Mac
You can add links to webpages or sections in a note. You can also link to related notes, like a trip itinerary and a list of recommended restaurants.
Note: All Notes features described in this guide are available when using iCloud notes. Some features aren’t available when using accounts from other providers.
Open Notes for me
Link to a webpage
Go to the Notes app  [IMG: ]  on your Mac.
In the note where you want to insert a link, do one of the following:
Choose Edit > Add Link, type or paste the webpage’s URL, then click OK.
Type or paste the webpage’s URL, then press the Space bar or the Return key.
If the URL does not automatically become a link, choose Edit > Substitutions > Smart Links to turn on Smart Links (a checkmark shows it’s on).
If you add a link to a Quick Note, a thumbnail of the Quick Note appears in the corner of the screen when you return to the linked content in the app.
Tip: To change some text that’s already in the note into a link, select the text, press Command-K, then type or paste the webpage’s URL.
Link to a section or another note
To create a section in a note, see Organize a note with sections and headings.
Go to the Notes app  [IMG: ]  on your Mac.
In the note where you want to add a link, choose Edit > Add Link.
Do any of the following:
Link to a section in the note: Click the menu next to Link to Section, then select a section. To customize the link name, turn on Use Section Title or enter a custom link name.
Note: If the title of a linked note or section changes, any link that uses the note or section title as its name updates automatically.
Link to another note: Start typing the title of the target note, then select it. To customize the link name, turn on Use Note Title or enter a custom link name.
Tip: To quickly link to another note, type “>>” in the note body, then enter the title of the target note. You can then link to a section in that note by typing “/,” then selecting a section.
Link to a section in another note: Link to another note, then tap Link to Section. Select a section.
Click OK.
Note: Notes that contain links to other notes may not be visible on devices with previous versions of macOS. See Why notes are hidden on some devices.
Edit and remove links
After you’ve added links to a note, you can edit or remove them.
Go to the Notes app  [IMG: ]  on your Mac.
Open the note with the link you want to change.
Control-click the link, then do one of the following:
Choose Attachments, then click Edit Link.
Choose Remove Link.
Change the color of links
You can change the color of links and highlights by changing the accent color and highlight color in Appearance settings on your Mac. (Changes you make there apply to links and highlights in all apps.) See Change Appearance settings.
