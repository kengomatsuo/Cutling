			Use keyboard shortcuts in Notes on iPad
If your iPad is connected to an iPad keyboard, you can use keyboard shortcuts to quickly perform actions in the Notes app.
Examples of keyboard shortcuts
Start a new note: Press Command-N.
Add a checklist: Press Shift-Command-L.
Create a bulleted list: Press Shift-Command-7.
Add a link: Press Command-K.
Add a divider line: Press Command-L.
Hide the sidebar: Press Control-Command-S.
Learn keyboard shortcuts
Press and hold the Globe ( [IMG: ] ) key or Command (⌘) key until the shortcuts appear.
