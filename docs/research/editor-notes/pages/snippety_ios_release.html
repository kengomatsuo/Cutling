iOS

13.2.74​

👉 Adjusted the app for iPhone Duo.

👉 Adjusted Snippety Keyboard for iPhone Duo.

👉 Added snippet version history - switch between up to 10 previous versions of a snippet.

👉 Improved snippet picker for Snippet Reference placeholder. You can now search snippets and browse them on the list.

👉 Added support for cursor placeholder allowing you to define where the cursor should be placed after snippet expansion.

👉 Added support for simulating Return and Tab keys allowing you to jump between form fields.

👉 Improved placeholder list allowing you to search and see the most recently used placeholders first.

13.1.73 (hotfix)​

👉 Fixed a crash on iPad that prevented the application from starting when the snippet database was empty.

👉 Fixed a crash on iPad that occurred when deleting the last snippet in a collection.

13.1.72​

👉 Improved Snippet Reference placeholders - you can now reference snippets by name, keyword, or ID.

👉 Improved performance and responsiveness when working with large snippet databases.

👉 Fixed an issue where the keyboard pop-up with alternative symbols could occasionally remain visible.

13.0.71​

Snippety App

👉 Added multiselect to the snippets list, allowing multiple snippets to be moved, tagged, duplicated, shared, or deleted at once.

👉 Improved image scaling and introduced an image editor for resizing and optimizing images in Rich Text snippets.

👉 Added a snippet sort order setting.

👉 Added search to the tags list.

👉 Improved the snippet editor, including form scrolling and full-screen template mode.

👉 Improved collections sidebar behavior in wide mode.

👉 Improved toolbar and tab bar behavior.

Snippety Keyboard

👉 Improved keyboard layout for all devices and modes.

👉 Added a full-size (desktop-like) keyboard for iPad.

👉 Added an option to expand only a selected tag with Snippet Expander.

👉 Reorganized Snippety Keyboard settings.

👉 Added URL and email automatic modes to the keyboard.

👉 Added an option to show Snippet Expander suggestions only when there is a match.

12.0.70​

Improved compatibility with iOS 27.

12.0.68​

👉 Tap & hold a key to show diacritics and alternative characters.

👉 Tap & hold the spacebar, then slide your finger to move the cursor.

👉 Snippet Expander now expands while typing without needing to switch modes manually.

👉 You can now set a prefix to avoid accidentally expanding snippets while typing.

👉 Snippet Expander on iPhone is now more compact and easier to use.

👉 Pressing spacebar after punctuation or digits automatically changes the keyboard to letters.

👉 Added auto-capitalization.

👉 Improved typing experience.

👉 You can now undo an expansion.

👉 Keyboard settings are now also available inside the app.

11.1.66​

📊 Added a "Track usage count & last used date for shared snippets" option. It is off by default, so using a shared snippet no longer syncs changes to your collaborators. Check Settings → General.

🤖 AI models are no longer a fixed list - pick a provider and type any model name. Check Settings → AI Assistant.

11.0.65​

🐛 Minor bug fixes and stability improvements.

11.0.64​

🔥 Added Conditional Blocks support. Dynamically show or hide parts of your snippet based on provided conditions. Find them under Snippet Editor → Insert Placeholder → Conditional Block.

🎨 Snippet previews now display placeholders as colored tags, matching their appearance on macOS.

⚙️ Added a new configuration option for both the app and keyboard, allowing you to choose what is displayed below each snippet title in the snippet list.

📝 Added a Note placeholder to let you add notes or comments to your snippets. Notes are visible only in the editor and are not included in the generated snippet.

👻 Added a "Hidden" option to the Selectable Value placeholder. Hidden values can be used in Conditional Blocks and Variable References without appearing in the generated snippet.

🎯 Extended the Variable Reference placeholder to support more variables.

⌨️ Added haptic feedback on key taps in the Snippety Keyboard. You can enable or disable it in the keyboard settings.

⌨️ Optimized Snippety Keyboard to reduce memory usage and improve performance.

10.2.61-63​

👉 Added support for trailing blank characters in the snippet template.

🎨 Refreshed the design of the snippet editor.

🗑️ Now you can delete all snippets by swiping left on the "All" collection.

10.1.60​

Added support for preselected items in the Multiselect Placeholder.

10.0.54-59​

Minor bug fixes and stability improvements.

We are shifting to a new model so everyone can try Snippety for free! A huge thank you to our early supporters: As a token of our appreciation, all existing users (prior version 10) have been automatically upgraded to a lifetime Pro plan for free.

9.2.52​

Improved Shortcuts integration:

👉 Refined naming for better clarity.

👉 Added new properties to give you even more control over your automations.

👉 Added shortcuts for tag management.

👉 Added predefined shortcuts that can be used with Siri.

Please note that some of your shortcuts may require migration due to these changes.

9.2.50​

⚙️ Added integration with Shortcuts app.

🤖 Updated OpenAI models.

9.2.48​

🪲 Improved cursor positioning when using "{@cursor@}" placeholder.

9.1.47​

🌄 Added support for clipboard images when using HTML format.

🤓 Added a keyboard option to disable Snippet Expander suggestions.

⌨️ Added a keyboard option to auto-switch back to typing mode.

💪 The keyboard now returns to its initial state after snippet expansion.

🤖 Fixed the AI Assistant's "Selection" placeholder mode.

9.0.46​

🔥 Snippet Expander is now available in Snippety Keyboard, letting you automatically expand snippets by typing keywords.

⌨️ The start screen for Snippety Keyboard is now configurable in the keyboard settings. You can choose from the following options: Collections List (default), Snippet Expander, Search, Selected Collection, or Last Collection.

🤓 On iPad, Snippety Keyboard now remembers if you hide the sidebar and keeps it hidden the next time you open it.

🪲 Performance and stability improvements.

8.1.55​

🤓 New text transformation: "Title Case (smart)" transforms text to title case while recognizing language components to avoid unnecessary capitalization.

📝 Sentence Case transformation has been improved to detect fully uppercased text, converting it to lowercase first before applying sentence case.

🤖 AI model can now be selected for each placeholder.

8.0.43​

🎨 Redesigned toolbars for quicker access to all essential actions.

📄 Improved snippet editor.

⚡ Improved tab bar behavior for smoother navigation.

🔎 Added search bars to format and collection lists.

🔢 New "Recent Formats" section showing your five most recently used formats.

⛅ Added iCloud status button for easier sync visibility.

⌨️ Added formatting toolbar above the keyboard when editing RTF documents.

⌨️ Added placeholder button above the keyboard.

🤖 Hide AI features in snippet editor when AI is not configured.

🤖 Added setting to hide AI features in snippet editor.

🖌️ UI enhancements optimized for iOS 26.

🐞 Fixed text wrapping issues in snippet previews.

🪲 Fixed various minor bugs.

7.3.41​

🔥 Updated app & keyboard appearance for iOS 26.

✂️ Updated app icon to match the new iOS 26 style.

🤖 Added support for new AI models.

🪲 Minor bug fixes and stability improvements.

7.2.40​

🔥 Added extended support for HTML snippets. You can now show preview and use HTML as an alternative to RTF. HTML snippets will be inserted as formatted text, as long as the target app supports HTML format.

🔄 Convert between HTML and Rich Text Format. Simply change the type in the snippet editor, and Snippety will automatically convert RTF to HTML or vice versa. This feature is useful for quickly formatting content with the built-in RTF editor, then converting it to HTML for fine-tuning.

🤖 New input modes for AI placeholder. You can now combine selected text or clipboard content with a prompt parameter. Use %@ in your instructions to define where the parameter will be inserted when running the snippet.

🤖 Unlocked AI features in China.

👉 Clipboard placeholder can now also apply one of the built-in text transformations.

👉 Text Transformation placeholder has been replaced by the Selected Text placeholder, which now also supports text transformation.

👉 Selectable Value placeholder now supports a default value, which will be applied when no value is selected.

🔔 Snippety Keyboard now shows a notification on the spacebar when a snippet is copied to the clipboard.

7.1.39​

🔎 Fixed issue with font scaling when using Rich Text snippets.

7.1.38​

🤖 Added support for custom and self-hosted AI APIs compatible with the OpenAI interface.

📖 Added application documentation. See: snippety.app/help.

🔗 Added new deeplinks: snippety://edit-snippet?id=<id>, snippety://collection?id=<NAME>.

7.0.37​

🏷️ Support for Tags: You can now add, manage, and filter snippets using configurable tags.

🎯 "Snippet Reference" Placeholder: Added a new placeholder for nesting snippets.

✏️ "Text Variable Reference" Placeholder: Added a new placeholder for referencing the same variable multiple times, with options for applying additional transformations.

🔥 A fresh new app icon that supports iOS 18 themes.

🤖 Added text transformations like camelCase, snake_case, and more for the "Text Transformation" placeholder.

📄 The "Multiselect" and "Selectable Value" placeholders now support multiline text. Use "n" to insert a new line.

6.1.36​

🖼️ Added support for images when using Clipboard placeholder.

🌍 Added Hyperlink placeholder.

⚙️ Added Editor & Preview settings (text wrap + font size).

💪 The AI placeholder provides more space in the text field for instructions.
