			 [IMG: ] Use the Ask Each Time variable in a shortcut 
The Ask Each Time variable allows you to adjust the parameters of an action at runtime. Using the Ask Each Time variable, you can wait to decide how an action should operate until the shortcut is run.
As your shortcut runs, each action is completed until the shortcut reaches an action that contains an Ask Each Time variable. At that point, the shortcut pauses, prompting you to update the action’s parameters. Once you tap Done, the shortcut continues its run.
 [IMG: Ask Each Time variable pausing the shortcut to request manually entered data.] To add the Ask Each Time variable to a parameter, tap the empty space in the action’s parameter row, then tap Ask Each Time. Now, each time the shortcut runs, you’re asked to confirm your option for that parameter. 
To insert an Ask Each Time variable in actions with text fields, tap the text field, then tap Ask Each Time (in the Variables bar that appears above the keyboard).
To insert an Ask Each Time variable to a repeat action, touch and hold the repeat parameter, then tap Ask Each time.
 [IMG: Ask Each Time variable token in the Date field of the Log Health Sample action.] Using the Ask Each Time variable on a parameter can be helpful for adjusting options on the fly, such as the Value in the Log Health Sample action.
