			Add a table in Notes on Mac
 [IMG: The Notes window showing the Table button—click it to add a table. Within the note content, a table column is selected so you can either add or remove columns or drag it to a new location.] Open Notes for me
Add a table
Go to the Notes app  [IMG: ]  on your Mac.
In a note, click where you want to add a table.
Click  [IMG: the Table button]  or choose Format > Table.
An empty table with two rows and two columns is added to your note.
Do any of the following:
Type in a cell: Click the cell, then start typing. 
You can use typing suggestions, if available.
Move within the table: Press Tab or use the arrow keys to move between table cells.
Paste text into the table: Click a cell, then choose Edit > Paste.
Named styles such as Monostyled or Subheading are removed.
Select multiple cells: Drag over the text in one or more cells.
If you want to select an entire row or column, see Manage rows and columns.
Move the table: Select the table, then drag it to the new location.
Tip: You can also copy a table from another app (such as Safari or Pages) and paste it into Notes. Some formatting is not supported in Notes.
Manage rows and columns
Go to the Notes app  [IMG: ]  on your Mac.
In a note with a table, click the table. Click  [IMG: the handle]  to the left of a row to select that row, or click  [IMG: the handle]  above a column to select that column.
Do any of the following:
Add or remove rows or columns: Click  [IMG: the down arrow] , then choose an option.
 [IMG: A table showing the down arrow for the column—click it to add or delete a column.] Tip: You can add a new row to the bottom of the table by pressing Tab or Return when you are in the last cell of the table.
Move a row or column: After selecting the row or column, click and hold until the row or column appears to rise off the table, then drag it to the new location.
Delete the content in a row or column: Choose Edit > Delete or press the Delete key.
If there’s no content in the row or column, this deletes the row or column immediately.
Convert text to a table
Go to the Notes app  [IMG: ]  on your Mac.
In a note, do one of the following:
Convert text to a table: Select one or more paragraphs of text in a note, then click  [IMG: the Table button]  or choose Format > Table. The selected text is converted to a table.
Convert a table back to text: Click anywhere in the table, click  [IMG: the Table Actions button] , then choose “Convert to text.”
