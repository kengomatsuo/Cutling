8.6.26.1782

November 18, 2026

This update includes additional improvements and bug fixes for the 8.6.26.1697 release, which introduced a new user experience and the ability to dynamically update the app's functionality. 8.6 client release is now at 100% rollout

Improvements

  • Refreshed fill-in window. The fill-in window's date picker and its prompts match the app's current look.
  • Other improvements: Preferences > Update shows the version of the latest update next to the app version, the same way About does, so you can check it even when the Dock icon is hidden. Updated translations.

Bug fixes

  • TextExpander starts normally again. Some people saw the app stay on the loading screen at every launch after editing a snippet group they manage. It now finishes loading. If the app can't read its local data, it shows "TextExpander is having trouble starting" with options to exit or clear the cache, instead of loading forever. 

8.6.26.1697

November 12, 2026

8.6 is currently in phased rollout. Please contact support@textexpander.com if you would like to get access right away. 

New Features (in 8.5 and 8.6) 

  • A new look. TextExpander 8.5 redesigns the Mac app, from the sidebar to the snippet editor. Your snippets, groups, and abbreviations stay where you left them.
    • Layout and fonts. Typography, spacing, and icons are updated across the app. The editor's default font is new and larger, unless you've picked your own.
    • Label and Abbreviation at the top. Both fields now sit above the snippet content instead of below it. Content type and Case move under Advanced options.
    • Labeled toolbar. Editor tools show their names next to their icons: Fill-ins, Date, Time, Math, Keyboard, and Cursor. You can collapse the toolbar to give the snippet more room.
    • Fits smaller windows. In a narrow window, side-by-side fields stack and less-used toolbar buttons move into a "More" menu.
    • Monospace abbreviations. Abbreviations in the snippet list and editor use a monospace font, so look-alike characters are easier to tell apart.
    • Dark mode. Dark mode follows your system settings and applies to the whole app, including menus, dialogs, and the title bar.
    • Snippet actions in one menu. Share, Duplicate, Move to, and Delete are in the "..." menu. When you duplicate a snippet, you can set its label and abbreviation before the copy is created.
    • Preferences in the main window. Settings open inside the app instead of in a separate window.
  • Updates in the background. TextExpander now keeps its interface up to date on its own. Updates download quietly and apply while you're away from the keyboard. Organizations that manage TextExpander updates through a device management solution can disable silent updates.

New features

  • Nested lists. Press Tab and Shift+Tab to indent and outdent list items, and bullets and numbers change style at each level. Expanded lists keep their formatting in Gmail, Outlook, Word, Google Docs, and Slack. Lists pasted from Word come in as real nested lists.

Improvements

  • Clearer Accessibility permission prompt. When TextExpander needs Accessibility permission, the message names the setting and walks you through turning it on.
  • Delete several Optional Sections at once. Highlight text that contains Optional or Conditional Sections, press Delete, and confirm once. One Undo restores the entire selection. .
  • Other improvements: date fill-ins default to the current year, and time options are labeled 12-hour and 24-hour.
  • Labels for Conditional Sections. Give a Conditional Section a label in the branch manager. The label shows on the section in the editor and next to the branch dropdown when you expand the snippet, so you know what you're choosing.
  • Search finds text in every branch. Search now matches text inside every branch of a Conditional Section, including nested ones, not only the branch shown by default.
  • Improved clipboard privacy. TextExpander now follows the privacy settings apps attach to copied content.
  • Updated sign-in screen. The sign-in screen matches the app's new design
  • Show at top with Conditional Sections. With Show at top turned on, the fill-in window now shows only the fill-ins from the branch you select. Fill-ins from other branches no longer appear, and fields in the selected branch no longer show twice.
  • Fill-in window and the app switcher. Expanding a snippet with fill-ins no longer moves TextExpander to the front of the Command-Tab app switcher.
  • Quick Actions on multiple displays. New Snippet, New from Clipboard, and Edit Last now open on the display you're using.
  • Reusing a cleared hotkey. After you clear a hotkey, you can assign the same key combination again without relaunching TextExpander.
  • Other improvements: Conditional Sections use new design colors in light and dark mode. The About window shows a simpler version number.

Bug fixes

  • Spelling and grammar checks work in long snippets, and their underlines stay in place as you scroll.

Security

  • Updated third-party components, including the app runtime, to address published security advisories.

8.4.8

September 28, 2026

New features

  • Delay macro. Add a configurable pause inside a snippet so expansion waits before continuing. Useful when the target app needs a moment to catch up, for example a form field that loads its options after focus. Found under Keyboard macros.

Improvements

  • Point font sizes survive paste and expansion. Text pasted into a snippet and text expanded out of one keep their point sizes in Word, Google Docs, and Outlook on the web.
  • Snippet suggestions ignore short strings. Suggestions now need at least 20 characters, which makes it far less likely that TextExpander offers to save a password you typed into an unprotected field.
  • Google Docs table borders come through. Copying a table from Google Docs into a snippet now picks up the cell borders instead of dropping them.
  • Today is highlighted in the date picker. The current date is marked, so you have a reference point when picking a date.
  • One set of spelling underlines. When TextExpander's spelling and grammar check is on in the snippet editor, macOS stops drawing its own squiggles underneath, so you no longer see two underlines on the same word.
  • Conditional section polish. The branch switcher is now a split pill, collapsed sections read more clearly, and the caps render correctly in dark mode.
  • Improved Hyperlink handling: Hyperlink targets now survive plain-text expansion, along with ability to open links in a new window.

Bug fixes

  • The Request Snippet feature is now visible for snippet groups in the Shared section.
  • Date and time elements can be added to fill-ins again. Clicking the calendar or clock icon inside a single-line or multi-line fill-in adds the element. Previously nothing happened.
  • Tables no longer fragment around a keyboard macro. A table that contains a keyboard macro in one of its cells expands as one table.
  • Typeahead in Popup fill-ins advances. Pressing the same letter repeatedly in a popup fill-in now steps through each matching entry and wraps around, instead of stopping on the first hit.
  • Conditional section caps behave when copied. Copying content that includes only the opening or closing cap of a conditional section no longer leaves a cap you cannot delete.
  • Branch names stick. Renaming a conditional branch no longer repopulates the original name as you delete it.
  • Other fixes: conditional sections render correctly in the Safari-based editor view.

Security

  • Improvements to URL handling in snippets.

8.4.6

August 5, 2026

Features marked Phased Rollout are being enabled for accounts in stages. Contact support@textexpander.com to request earlier access.

New Features

  • Conditional Sections in snippets (Phased Rollout). Build if/then branching directly into a snippet: wrap content in a conditional section with named branches, and the fill-in window shows a dropdown that reveals only the selected branch's content and fill-ins. Sections nest, branches are unlimited, and you can embed other snippets inside a branch. The expanded result reads as one clean document with no leftover blank lines.
  • Spell check and grammar suggestions in the snippet editor (Phased Rollout). Misspellings get a dashed red underline and grammar suggestions a wavy purple one. Click an underline to see suggestions, then apply or ignore. The checker skips macros, the spacing around them, and script snippets, and it also works in the default text fields of fill-in dialogs. Checking is English (en-US) for now. While it is active, the built-in system spell check turns off in that editor so you see only one set of underlines.
  • Sign in with your browser. The sign-in screen now offers a single "Sign in with browser" button that hands authentication to your browser session, so you never type your password into the app window. A "Sign in manually" link keeps the email and password form one click away.

Improvements

  • Clearer Secure Input status. When macOS Secure Input pauses expansion, the menu bar icon now shows a prominent red slash, and notifications identify the source more accurately, showing "macOS Secure Input" when the system itself is holding it (for example, right after waking or unlocking your Mac).
  • Group sharing is easier to find. Selecting a snippet group now shows an actions menu in the header with Share, Group Settings, and Delete, replacing the buried right-click and gear-icon paths.

Bug fixes

  • Fixed a crash when using Print All Groups with groups containing rich text snippets.
  • Fixed date and time macros not inserting into single-line and multi-line fill-in fields.
  • Fixed the Dock icon reappearing, and refusing to hide again, after opening TextExpander via Spotlight, Alfred, or Finder while it was running in the background with the Dock icon hidden.
  • Fixed a small square artifact appearing in the center of the Delete Snippet confirmation dialog on some macOS versions.
  • Other fixes: the snippet type dropdown is now disabled for snippets the editor cannot safely edit, matching the editor itself, and switching a snippet to a script type and back no longer strips the compatibility guard that protects newer snippets from older clients.
