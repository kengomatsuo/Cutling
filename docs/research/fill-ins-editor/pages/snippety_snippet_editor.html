Snippet Editor

  1. Snippet Name: Use this field to name your snippet. The name is used for searching and sorting snippets.
  2. Snippet Keyword: Use this field to define a keyword for your snippet. The keyword is used to expand snippets while typing (Snippet Expander). It's best when keywords don't overlap with other snippets, but Snippety supports it by providing a short delay before expanding the snippet to allow you to continue typing.
  3. Snippet Description: Use this field to add a description to your snippet. The description is to help you remember the purpose of the snippet.
  4. Snippet Collection: Use this field to select the collection where you want to save the snippet. You can create a new collection by just typing the name of the collection. Collections are generated automatically when there is any snippet in them.
  5. Snippet Tags: Use this button to add tags to your snippet. Tags are used to categorize snippets and make them easier to find. Here you can also add the snippet to Quick Access Menu.
  6. Snippet Actions: Here you can find main actions like inserting placeholders, AI features, etc. If you switch syntax to Rich Text (10.), you will be able to insert images and format the text. Clicking on an inserted image opens the Image Editor.
  7. Wrap Text: Click on this button to toggle word wrap. This option is unavailable for RTF snippets, because they require a fixed width to align text.
  8. Snippet Content: Use this field to define the content of your snippet. You can use placeholders to make your snippet dynamic.
  9. Placeholders: they are enclosed in curly braces with @ symbool, e.g., {@text|Field@}. You can create them using the Insert Placeholder button or by typing them directly once you know the syntax.
  10. Syntax: Click on this button (or press Shift + CMD + F) to switch between Plain Text, Rich Text, or any other supported syntax. The are 4 main types: Plain Text, Rich Text, Markdown, and HTML. There are also other formats like those used for programming or configuration files. The picker is searchable - just start typing the format name and use the arrow keys and Enter to select it. Recently used formats are listed first.

Testing Snippets​

Since version 9.3.91, you can use CMD+S shortcut to save the snippet without closing the editor. This is useful when you want to quickly save the snippet and test it.

To use a snippet without closing the editor, just open another application next to Snippety and type the keyword as you would normally do.

You can also use the built-in Test (CMD+T) feature to test the snippet without leaving the app.

Shortcuts​

There are many shortcuts available in the editor. You can find them by hovering your cursor over the buttons or in Settings -> Shortcuts.
