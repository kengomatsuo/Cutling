This article describes the KeyboardKit status engine.

## Overview
KeyboardKit has ways to check the system status of any keyboard extension, like if it’s enabled in System Settings, if it has Full Access, if it’s actively being used, etc.

## Context
KeyboardKit has a  class with observable state, that can be used to observe the status of your keyboard.
struct MyView: View {

    @StateObject private var status = KeyboardStatusContext(bundleId: "com.myapp.*")

    var body: some View {
        VStack {
            Text("Enabled: \(status.isKeyboardEnabled.description)")
            Text("Active: \(status.isKeyboardActive.description)")
            Text("Full Access: \(status.isFullAccessEnabled.description)")
        }
    }
}
