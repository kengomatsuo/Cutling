Set up on iPhone and iPad
iOS doesn’t let apps watch the clipboard in the background. These steps get PastePal saving what you copy with as few taps as possible.
1. Allow paste without the popup
Open the iOS Settings app and find PastePal.
Tap Paste from Other Apps and choose Allow.
If you don’t see that option yet, open PastePal once after copying something and accept the paste popup. The option shows up after that. See Allow Paste.
2. Save when you open the app
In PastePal settings, turn on Save Clipboard on Open. Now copy something anywhere, switch to PastePal, and it’s saved.
3. Save in the background (optional)
In PastePal settings, turn on Monitor Clipboard, then Background Monitoring. PastePal starts a small Picture in Picture player that keeps it running, so it can save clips while you use other apps. See Background Monitoring.
4. Add the PastePal keyboard
The keyboard lets you paste saved clips in any app.
Open Settings ▸ General ▸ Keyboard ▸ Keyboards ▸ Add New Keyboard and pick PastePal.
Open Settings ▸ PastePal ▸ Keyboards and turn on Allow Full Access, so the keyboard can read the clipboard.
In any text field, tap the globe key to switch to PastePal.
