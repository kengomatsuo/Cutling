# Porting list for direction A (ASG105), fetched 2026-11-21

Full rows with permalinks, licences, stars and push dates: `notes.md`. Findings that shape the choice: no found project has a Settings-steps video with Reduce Motion handling in permissive code; the only one that honours the system autoplay switch (Tangem) is proprietary; the most popular onboarding package (OnboardingKit) is archived; UIOnboarding, the best Apple-style welcome, is UIKit. Nothing here persists progress across a relaunch except OnboardingKit's `presentationCount`. Apple has no sample project on GitHub with a welcome flow. No further iOS keyboard setup in SwiftUI turned up beyond the saved hex, type4me, ClipKeyboard and Dictus.

Ranked, port in this order (all rewritten in Apple frameworks, nothing added as a package):

1. **Page 2 video: Obscura `LoopingVideoPlayer.swift` + `InstallSystemExtensionView.swift`** (GPL-3.0, so rewrite, not copy). Take: muted `AVQueuePlayer` + `AVPlayerLooper`, touches disabled, play on appear and pause on disappear; page shape of one paragraph, one Open Settings button, video of the steps. Add from Apple's docs and Tangem's idea (read only, proprietary): check `UIAccessibility.isVideoAutoplayEnabled`, observe its change notification, show a still frame when off.
2. **Page 2 player layer: fullmoon `MoonAnimationView.swift`** (MIT) with Planetary `NoControlsVideoPlayer.swift` (MPL-2.0). Take: `AVPlayerLayer` view with no controls, `.resizeAspect` for a phone recording, `.ambient` audio session, strong reference to the looper.
3. **Page 1: UIOnboarding `UIOnboardingViewController.swift`, `UIOnboardingCell.swift`, `UIOnboardingFeature.swift`** (MIT) and its README image. Take: icon, "Welcome to" over the name in grey, three icon rows, one Continue; Reduce Motion halves the spring instead of removing it. Compare with `../../../../Cutling/AppleSheet.swift`.
4. **Flow state and persistence: OnboardingKit `OnboardingFlowState.swift`, `OnboardingFlowContainer.swift`, `Onboarding.swift`** (MIT, archived). Take: index state plus a `UserDefaults` flag keyed by onboarding id; change it to store completion, not presentation.
5. **Accessibility: Wikipedia `WMFAppOnboardingView.swift`** (MIT). Take: `.dynamicTypeSize(...accessibility2)` over the whole flow, a labelled page indicator, an enum of steps. Add Bitwarden's `AppExtensionView.swift` idea (GPL, rewrite) for a page that changes its title and line when the app detects the keyboard.
