Snippet Trigger

The Snippet Trigger runs a workflow by typing anywhere. It activates like a regular text expansion snippet but can perform any action in a workflow.

Page Index

  • Advanced

Setup

Keyword sets the text trigger for the snippet.

Focused App Variable determines if a variable should be set with the bundle ID of the focused app, so you can differentiate later in the workflow.

Shared Prefix and Suffix are shared across all Snippet Triggers and define the extra text you need to type around the Keyword for it to activate.

Snippet Viewer controls if Snippet Triggers should be available in the Snippet Viewer.

Connection Ideas

Construct complex snippets by connecting the Snippet Trigger to a Keyword Input to ask for custom text, save the output to a variable with the Arg and Vars Utility, and paste the constructed text to the frontmost app with a Copy to Clipboard Output.

Use a List Filter Input instead of a Keyword Input when wanting to pick from predefined choices instead of freeform text.

Advanced

Important

When importing a new workflow, Alfred strips Hotkey Triggers and Snippet Triggers, meaning you have to configure the values you want for these (if any). This is done to prevent clashes with other personal Hotkeys and Snippets you may have configured.

If you set the same keyword for a Snippet Trigger and a regular text expansion snippet, the Snippet Trigger takes precedence.
