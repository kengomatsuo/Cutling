# Cutling 2.0: words for the in-app event and What's New

Cards ASG152 and ASG150. Written 2026-11-22 from `2.0-words-brief.md`. Nothing here is uploaded and
`fastlane/metadata*` is untouched. Part 1 is the English. Part 2 is the meaning brief that writers in
the other languages get; it quotes none of Part 1, so it can be handed over alone. English was written
from the same meanings and is a peer of the other languages, not their source.

## Part 1: the English lines

### Where the words start

The buyer's own complaints, from `~/Repositories/undirect/docs/research/cutling-voice-of-customer.md`:
"type out the same info over and over and over" (A1), "ability to add custom variables", from someone
who wanted to swap a name across many snippets (A7), "do you support variables in the snippets" (R21),
"wish that I could format my snippets with bold, italics" (A8), and a library that 100 cutlings of
1,000 characters could not hold (gap 5: long canned emails).

What that buyer wanted instead: to write a reply one time, have it go out with the right name and the
right date, and never fix it by hand afterwards. The event text says that and leaves the word
"variables" out, because the people who ask for variables by name are the few; the many have a canned
reply and a name to change.

### In-App Event, no sale

Counts include spaces. Limits: name 30, short description 50, long description 120.

| Set | Name | Short description | Long description |
|---|---|---|---|
| A, the one to ship | The Write-It-Once Update (24) | One saved reply. A different name every time. (45) | Cutling asks for the name, adds today's date and types the rest. You write a reply once and stop fixing it by hand. (115) |
| B, named for the act | Fill In the Blanks (18) | Never retype a reply to change one name. (40) | Leave a blank for the name or the order number and Cutling asks for it as it types. Dates fill themselves in. (109) |
| C, the owner's Undirect cadence | The Write-It-Once Update (24) | No retyping. No changing the name by hand. (42) | Whoever you're writing to, Cutling asks for the name and types the rest. You just write it once. (96) |

Why A. The name is the buyer's end state, as "Stay-Put" was. The card line is one moment the buyer
knows: the same reply, going to a different person. The details line holds what the card had no room
for, in the order it happens on the phone (Cutling asks, adds the date, types), and ends on what the
buyer does once and what they stop doing.

What each alternate costs. B's name says what the buyer does, not what they get, and its long
description says "as it types", which is loose: the keyboard asks first and types nothing until the
blank is filled. C's short description is the shape of the owner's approved "No surprise redirects.
No broken Back button."; the prose scanner flags a run of two "No" sentences, and it says what stops
without saying what the buyer now has.

On "Update" in the name. The badge above it reads MAJOR UPDATE, so the card says the word twice, and
none of the 85 live event names in Undirect's research uses it. The owner knew that when he chose "The
Stay-Put Update", so A follows his choice. "Write It Once" (13) is the same name without it.

### In-App Event, with the sale

Name and short description as in set A. Only the long description changes, since Apple calls a price
promotion alone a weak event and the sale is news to someone deciding, not to someone who already paid.

| Line | Text |
|---|---|
| Long description | Cutling asks for the name, adds today's date and types the rest. You just write it once. On sale for Black Friday. (114) |
| Short description, only if the sale must show on the card | One reply, a new name each time. On sale now. (45) |

No price and no percentage. Apple's pages say "Don't include specific prices"; whether "40% off" counts
as one is not stated on any page read, so it is left out.

### What's New, iPhone and iPad (1,393 characters of 4,000)

```
Write a reply once and use it for everyone. A cutling can now hold a blank for the part that changes, such as a name or an order number. Tap the cutling and the Cutling keyboard asks for the name, with the ones you used before one tap away, then types the whole reply. Or type the name first and tap the cutling.

Dates fill themselves in. Put today's date, tomorrow, a week from now or the time into a cutling and it is right on the day you use it. A cutling can also offer a choice (Basic or Pro, say), take in the text you last copied, or leave the cursor where you want to carry on typing. All of these are under Variables when you edit a cutling. Braces you typed yourself stay as plain text, so the cutlings you already have work as before.

Write cutlings the way you write in Notes. The text now opens as its own page with bold, italic, underline, strikethrough, highlight, monospace and links, and with bulleted, dashed and numbered lists.

There is far more room: 5,000 text cutlings and 500 images, up from 100 and 25. Each cutling can run to 10,000 characters, so a whole email fits.

Every key on the Cutling keyboard types now. Tap a formatted cutling and it types like the rest; touch and hold it to copy it with its formatting.

If you never finished adding the Cutling keyboard, open Keyboard Setup in Cutling. The new guide plays the three steps in Settings as a short video.
```

### What's New, Mac (815 characters of 4,000)

```
Write a reply once and use it for everyone. A cutling can now hold a blank for the part that changes, such as a name or an order number. Pick the cutling with ⌘⇧V and a short form asks for the name before it pastes, with the ones you used before one click away.

Dates fill themselves in. Put today's date, tomorrow, a week from now or the time into a cutling and it is right on the day you use it. A cutling can also offer a choice (Basic or Pro, say) or take in the text you last copied. All of these are under Add Variable, right below the text when you edit a cutling. Braces you typed yourself stay as plain text, so the cutlings you already have paste as before.

There is far more room: 5,000 text cutlings and 500 images, up from 100 and 25. Each cutling can run to 10,000 characters, so a whole email fits.
```

The Mac text leaves out four things on purpose. The Notes-like page, the keyboard's "every key types"
and the setup guide are iPhone and iPad only (`TextPageView.swift` and `FormatPanel.swift` sit under
`#if os(iOS)`). The cursor variable is left out because the Mac picker places the cursor only when
direct paste is on, and direct paste is off by default (`docs/fill-ins.md`).

### Open points

1. Underline, highlight and the three kinds of list are in the working tree as uncommitted edits to
   `FormatPanel.swift` and `RichText.swift` (session cutling-format), not in a commit yet. The brief
   says to write them as included, and they are. If they do not ship in 2.0, the iPhone and iPad
   paragraph's second sentence becomes: "The text now opens as its own page with bold, italic,
   strikethrough, monospace and links."
2. The sale sentence goes stale. After an event is published only its dates can be changed
   (`docs/aso/in-app-events.md`), the sale ends on November 30 and an event may run 31 days. "On sale
   for Black Friday" is accurate only while the sale runs, so the sale version fits an event that ends
   with the sale. For a longer event, ship the version without it.
3. The paragraph that names Notes compares Cutling's editor to an Apple app by name. Whether App Review
   objects to that in What's New was not researched in this session. Without the name, the paragraph
   drops its first sentence and starts at "The text now opens as its own page".
4. The editor's labels "Variables", "Add Variable", "Ask Each Time" and "Choice" have no translation in
   any of the 76 `Localizable.strings` files yet ("Keyboard Setup" has one in all 76), and
   `2.0-glossary.json` beside this file still lists the older "Add Fill-in" and no "Variables". A store
   text can only name the control by the word the app shows, so those strings come before, or in the
   same pass as, the What's New in each language.
5. The App Store shows only the first lines of What's New before a "more" link. How many characters
   that is was not measured in this session; both texts put the whole point in their first sentence.

## Part 2: meaning brief for writers

Hand a writer this part and the product words below, never Part 1. No English line exists for them to
follow. Each writer returns, per line, the text, a literal back-translation and its character count.

### The product, in a few lines

Cutling keeps pieces of text and images a person sends again and again (an address, bank details, a
standard reply to customers) and types them into any app from its own keyboard on iPhone and iPad. On
the Mac a small picker, opened with ⌘⇧V, pastes them. Version 2.0 is its biggest update. The main new
thing: a saved text can have a gap in it for the part that differs each time, such as the other
person's name, and can hold a date that is always the current one.

Product words. The app's name and the word for one saved item (a "cutling") are written the way the
app's own strings in that language write them: some languages keep "Cutling" in Latin letters and some
spell it in their own script. `docs/aso/events/2.0-glossary.json` lists both per language, taken from
`Cutling/<lproj>/Localizable.strings`. The gap is called by the word that language's in-app What's New
row uses (the key `Blanks and Dates`).
Button and menu names are quoted exactly as the app shows them in that language: the keys `Variables`,
`Add Variable` and `Keyboard Setup`. ⌘⇧V stays as symbols. Numbers take the language's own grouping
(5,000 may be 5.000 or 5 000). The plan names used as an example of a choice may be any two plan names
natural in that language.

Rules that bind every line. Say what the person gets, in the words they would use for their own
trouble; no maker's words for the mechanism (no "variable", "placeholder", "template", "dynamic" in the
event text). No price, no percentage, no country or city. No exclamation marks in a row, no line in
all capitals.

### Event name

- Where: the App Store's In-App Event card, in white over a picture, directly under a small badge
  that reads "major update" in the store's language; the same name is the title of the event's page.
- Reader and moment: someone who already has Cutling and is scrolling search results on an iPhone or
  iPad, or a visitor on Cutling's store page. They give it about a second.
- Meaning: a nickname for this update, the kind a person would give it when telling a friend. The
  nickname says that from now on you write a message one single time and never write it again.
- Register: warm and plain. Not an instruction to the reader, not a slogan, not the name of a feature.
- Form: a language may build the nickname with its word for "update" or without it; with the badge's
  word right above, leave it out wherever the repeat reads clumsy. Title case where the language has it.
- Length: 30 characters at most, spaces included.

### Event short description

- Where: one line under the name on the same card, smaller, white over the picture. It must fit one
  line.
- Reader and moment: as for the name; this is the line that tells them what changed for them.
- Meaning: two beats. They keep one reply, saved a single time. Each time they use it, it carries a
  different person's name.
- Register: two short statements or one short sentence, sentence case, said to the reader as a fact.
  No question, no command.
- Length: 50 characters at most.

### Event long description

- Where: the event's own page, under the name in large type. The reader tapped the card to get here.
- Reader and moment: curious enough to tap; wants to know what happens when they use it.
- Meaning, first sentence: what happens on the phone, in this order. Cutling asks the person for the
  name. Cutling puts in the current date by itself. Cutling types everything else. Cutling asks before
  it types; do not write that it asks while typing.
- Meaning, second sentence: the result for them. They write a reply one time, and they stop correcting
  it by hand afterwards.
- Register: sentence case, full stops, the app named by its name. Two sentences.
- Length: 120 characters at most.

### Event long description, sale version

- Where, reader, register and length: as above. Three short sentences.
- Meaning, first sentence: the same as the first sentence above.
- Meaning, second sentence: they write it one time only. Short.
- Meaning, third sentence: Cutling is on sale for Black Friday. Name the sale the way shoppers in that
  storefront name it. No price, no percentage, no dates.

### Event short description, sale on the card

- Use only if the owner wants the sale on the card. Where, reader and length as the short description.
- Meaning: one reply that takes a new name each time it is used; and it is on sale now.

### What's New, iPhone and iPad

- Where: the "What's New" text of version 2.0 on the App Store, shown on Cutling's page and in the
  Updates list. Only the first lines show until the reader taps to read more.
- Reader and moment: someone who owns Cutling, possibly someone who stopped using it, deciding whether
  to open it again. They know what a cutling is.
- Register: the maker telling a customer what they can now do. "You", full sentences, plain
  paragraphs with a blank line between them, no headings, no bullets, no emoji.
- Length: 4,000 characters at most; about 1,400 is right. Six paragraphs, in this order.

1. Opens with the whole point in one short sentence: write a reply once and it serves for everyone you
   send it to. Then how. A cutling can now hold a gap for the part that changes; give a name and an
   order number as examples. When they tap that cutling, the Cutling keyboard asks for the name, shows
   the names they used before so one tap picks one, and then types the complete reply. Last, the
   shortcut: they can also type the name first and then tap the cutling.
2. Dates need nothing from them. A cutling can hold today's date, tomorrow's, the date a week from now
   or the time, and it comes out correct on the day it is used. A cutling can also offer a choice
   between options (two plan names as the example), bring in the text they copied last, or leave the
   cursor at the spot where they want to keep typing. All of these are found under the button named
   `Variables` while editing a cutling. Closing reassurance: curly braces they typed themselves remain
   ordinary text, so the cutlings they already have behave as they did.
3. They can write a cutling the way they write in Apple's Notes app, with nothing new to learn. The
   cutling's text now opens as a page of its own with these formats: bold, italic, underline,
   strikethrough, highlight, monospace, links, and bulleted, dashed and numbered lists. Name the Notes
   app as the App Store in that language names it.
4. Far more room. 5,000 text cutlings and 500 images, where it was 100 and 25. One cutling can be up
   to 10,000 characters, which is enough for a whole email.
5. Every key on the Cutling keyboard now types. Tapping a cutling that has formatting types it like any
   other. Touching and holding it copies it with its formatting kept.
6. For someone who never finished adding the Cutling keyboard: open `Keyboard Setup` in Cutling. The
   new guide shows the three steps in the Settings app as a short video.

### What's New, Mac

- Where: the "What's New" text of version 2.0 on the Mac App Store.
- Reader and moment: someone who owns Cutling on a Mac and uses the picker from the menu bar.
- Register: as for iPhone and iPad, with "click" where a Mac is clicked.
- Length: 4,000 characters at most; about 800 is right. Three paragraphs, in this order. Nothing about
  the iPhone keyboard, the Notes-like page, the setup guide or the cursor.

1. Opens with the same whole point: write a reply once and it serves for everyone. A cutling can now
   hold a gap for the part that changes; a name and an order number as examples. When they pick that
   cutling with ⌘⇧V, a short form asks for the name before it pastes, and the names they used before
   are one click away.
2. Dates need nothing from them: today's date, tomorrow's, a week from now or the time, correct on the
   day the cutling is used. A cutling can also offer a choice between options (two plan names as the
   example) or bring in the text they copied last. All of these are under the button named
   `Add Variable`, which sits right below the text while editing a cutling. Closing reassurance: curly
   braces they typed themselves remain ordinary text, so the cutlings they already have paste as they
   did.
3. Far more room: 5,000 text cutlings and 500 images, where it was 100 and 25. One cutling can be up
   to 10,000 characters, which is enough for a whole email.
