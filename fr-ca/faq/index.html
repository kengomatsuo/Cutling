Foire aux questions

C’est quoi, un « cutling »?

Un cutling, c’est un élément enregistré : un bout de texte ou une image que vous voulez garder à portée de main. Voyez-le comme une bouture prise dans votre presse-papiers. Vous la replantez dans n’importe quelle app, aussi souvent que vous voulez.

Comment configurer le clavier Cutling?

Allez dans Réglages > Général > Clavier > Claviers > Ajouter un clavier, puis choisissez Cutling. Touchez ensuite Cutling et activez « Autoriser l’accès complet ». Un guide de configuration se trouve aussi dans l’app.

Pourquoi le clavier a-t-il besoin de l’accès complet?

L’accès complet permet au clavier de lire vos cutlings dans le stockage local de l’appareil pour vous les montrer. Cutling ne s’en sert pas pour enregistrer vos frappes, se connecter à Internet ni envoyer quoi que ce soit. Tout reste sur l’appareil.

Mes données sont-elles en sécurité?

Oui. Aucune donnée n’est recueillie : aucune statistique d’utilisation, aucun pistage, aucun rapport de plantage, aucun SDK tiers. Vos cutlings sont stockés localement sur l’appareil, ou dans votre propre compte iCloud si vous activez la synchronisation. Le développeur n’a aucun moyen d’y accéder.

Comment fonctionne la synchronisation iCloud?

Une fois activée, elle passe par la base de données privée CloudKit d’Apple pour garder vos cutlings à jour sur vos appareils Apple. Vous seul y avez accès, par votre compte Apple. Le développeur n’a aucun accès aux données synchronisées. La synchronisation est facultative et se désactive en tout temps dans les réglages.

Y a-t-il une limite au nombre de cutlings?

Vous pouvez garder jusqu’à 100 cutlings texte et 25 cutlings image. Chaque cutling texte peut contenir jusqu’à 1 000 caractères.

Est-ce que Cutling fonctionne sur Mac?

Oui. Sur Mac, Cutling se loge dans la barre des menus et se rappelle de partout par un raccourci clavier global. Vous choisissez un cutling et il est collé directement dans l’app que vous utilisiez. Avec la synchronisation iCloud activée, vos cutlings sont les mêmes sur iPhone, iPad et Mac.

Y a-t-il un abonnement ou des achats intégrés?

Non. Cutling est un achat unique : aucun abonnement, aucun achat intégré, aucune pub. Vous payez une fois, c’est à vous pour de bon.

Qu’arrive-t-il aux cutlings supprimés?

Ils passent dans le dossier « Supprimés récemment », où ils restent 30 jours. Vous pouvez les récupérer pendant ce temps, ou les laisser disparaître d’eux-mêmes.

Comment installer la version Mac?

Il y a deux façons de faire, toutes les deux sur la page de téléchargement. Depuis le Mac App Store, l’installation se fait comme pour n’importe quelle app. Sinon, téléchargez-la gratuitement, directement d’ici : elle est signée avec un Developer ID et notarisée par Apple, alors elle s’ouvre normalement, sans avertissement de sécurité. Ouvrez le DMG et glissez Cutling dans votre dossier Applications.

C’est quoi, le collage direct sur Mac, et pourquoi demande-t-il l’accès à l’accessibilité?

Le collage direct est facultatif. Quand il est activé, choisir un cutling dans le sélecteur envoie une seule frappe ⌘V à l’app que vous utilisiez, et le texte arrive à l’endroit du curseur. macOS exige l’accès à l’accessibilité pour envoyer cette frappe. L’option est désactivée par défaut, et sans elle Cutling copie simplement dans le presse-papiers pour que vous colliez vous-même.
